# blender-arch-tools
A collection of open-source Blender scripts, workflow guides, and automation tools for architectural visualization.

## Features

- Apply scale automatically
- Batch rename objects
- Scene cleanup
- Camera setup
- Cycles render presets
- SketchUp to Blender workflow
- Documentation for beginners

## Why this project?

Architectural visualization often involves repetitive tasks. This project aims to make Blender easier and faster for architects and students by providing reusable scripts and practical workflow documentation.

## Installation

1. Download or clone this repository.
2. Open Blender.
3. Go to the **Scripting** workspace.
4. Open any script from the `scripts/` folder.
5. Click **Run Script**.
